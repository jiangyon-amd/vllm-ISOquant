# Kernel Optimization Strategies

## Baseline Performance
[baseline]
- N=2,H=2: 35.4us
- N=8192,H=8: 252.2us

## Strategy 1: Vectorized PiT loads
[priority:normal][successful] Use float2 loads for PiT matrix to halve memory transactions
- Expected: +10-20%
- Target: GEMV
- Result: float4 vectorized loads for PiT into LDS

## Strategy 2: Register-blocked GEMV
[priority:normal][successful] Process 2-4 input dims per iteration with unrolling
- Expected: +15-25%
- Target: GEMV
- Result: 4x unrolling with FMA instructions

## Strategy 3: Remove __syncthreads
[priority:normal][partial] Single wavefront doesn't need sync barrier
- Expected: +5-10%
- Target: Overhead
- Result: Wave barrier helps for single wavefront but multi-wavefront needs __syncthreads

## Strategy 4: Loop unrolling
[priority:normal][successful] Unroll GEMV inner loop with #pragma unroll
- Expected: +10-15%
- Target: GEMV
- Result: 8x unrolling in GEMV inner loop

## Strategy 5: Vectorized key/value loads
[priority:normal][skipped] Use float2 for bf16 loads
- Expected: +5-10%
- Target: Memory
- Result: Not needed - LDS PiT approach is more effective

## Strategy 6: Multi-wavefront blocks with LDS PiT
[priority:normal][successful] Use 4 wavefronts per block to share PiT matrix via LDS, reducing global memory bandwidth
- Expected: +40%
- Target: Large NH (>256)
- Result: N=8192,H=8: 252us -> 140us (44% improvement)
