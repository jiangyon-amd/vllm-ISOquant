# Kernel Optimization Strategies

## Baseline Performance
[baseline]
- M=1: 5.9µs
- M=4: 8.1µs
- M=32: 8.4µs

## Strategy 1: Vectorized Rotation Load
[priority:normal][successful] Use bf16x8 vectorized loads for rotation matrix instead of scalar loads
- Expected: +20-30%
- Target: rotation load
- Result: v8 kernel: M=1: 4.6µs (22% faster), M=4: 6.3µs (22% faster), M=32: 6.2µs (26% faster)

## Strategy 2: Direct FP4 Global Store
[priority:normal][successful] Store FP4 directly to global memory without LDS staging
- Expected: +10%
- Target: FP4 output
- Result: Combined with vectorized load in v8 kernel

## Strategy 3: 32x32x16 MFMA
[priority:normal][failed] Use larger MFMA instruction for fewer calls
- Expected: +30%
- Target: MFMA compute
- Result: Complex lane mapping made implementation difficult, did not pursue
