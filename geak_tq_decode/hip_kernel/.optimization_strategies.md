# Kernel Optimization Strategies

## Baseline Performance
[baseline]
- Kernel: tq_decode_stage1_v12
- Time: 133.7us
- Target: <100us
- BW_util: 34%

## Strategy 1: 4-warp interleaved
[priority:normal][failed] Extend 2-warp to 4-warp interleaved processing for 2x memory parallelism
- Expected: +20-30%
- Target: Memory latency hiding
- Result: 4-warp and 3-warp both slower than 2-warp

## Strategy 2: Software prefetch
[priority:normal][pending] Prefetch next BLOCK_KV tokens while processing current
- Expected: +10-15%
- Target: Memory latency hiding

## Strategy 3: Batch page-table lookup
[priority:normal][pending] Pre-load all page entries before KV loop
- Expected: +5-10%
- Target: Reduce dependent loads

## Strategy 4: Process 2 KV per thread
[priority:normal][pending] Each thread handles 2 KV tokens simultaneously
- Expected: +10-15%
- Target: ILP improvement

## Strategy 5: Reduce VGPR for occupancy
[priority:normal][pending] Use amdgpu_num_vgpr to force lower register usage
- Expected: +5-10%
- Target: Higher occupancy

# Note: Best result so far: v52 with 2 warps, BLOCK_KV=4, non-temporal loads for values = 112.6 us (13% from target)
